$ nv set vrf default router bgp neighbor swp2 timers hold --help   (leaf01)
usage: 
  nv [options] set vrf <vrf-id> router bgp neighbor <neighbor-id> timers hold <arg>

Description:
  hold           Hold timer.  If `none`, keepalives from the peer are not tracked and the peering session will not experience a hold timeout.  If `auto`, the global value is used.  This is the default.

Identifiers:
  <vrf-id>       VRF (vrf-name)
  <neighbor-id>  Peer ID (ipv6 | ipv4 | interface-name)
  <arg>           (default:auto | enum:auto, none | integer:3 - 65535 |
                 string)

General Options:
  -h, --help     Show help.
